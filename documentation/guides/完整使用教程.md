## 1. 它是什么，不是什么

**工作流**：`获取对话 → 人工核对 → 策略判断 → 生成与排序候选 → 你选择草稿 → 你自己发送`。

- **不自动发消息**。程序最多生成草稿或填入输入框，发送永远由你手动完成。
- **不读心**。区分「可见事实 / 合理推测 / 仍未知」，不编造过去经历、承诺或成功概率。
- **不以得到某个人为目标**。禁止操控、施压、贬低、虚假时间限制。

**Jev 的位置**（最容易搞混的一点）：Jev 是 [TypeSafe AI](https://www.typesafe.ai) 的 **System One 判定模型**，闭源 API，不是聊天模型。

| 层 | 谁来做 |
| --- | --- |
| 读屏 / OCR | Apple Vision、RapidOCR、ML Kit、或视觉模型 |
| **策略判断**（七选一：承接 / 降压 / 调侃 / 轻推 / 约见 / 澄清 / 收线） | **Jev**，或 DeepSeek 备选 |
| 回复文案、口吻改写、详细解释 | DeepSeek / OpenRouter / OpenAI-compatible LLM |
| 结构化判定接口 | `POST https://api.typesafe.ai/v1/systemone`，`Authorization: Bearer <API_KEY>`，字段 `state` / `model` / `questions`，常用模型 `jev-latest` |

Jev 不生成文字、不写解释、不读图、不替代 LLM。所以「接入 Jev」不是把聊天模型换掉，而是在第 2 层加一个判定器。

## 2. 功能总览

> 逐模块清单与「上游已有 / 本分支新增」标注见 [功能总览.md](./功能总览.md)。

| 模块 | 能力 |
| --- | --- |
| 对话获取 | Mac 读屏、Windows 窗口采集、Android 无障碍树 + 截屏 OCR、iOS 截图 / 粘贴 / 快捷指令 |
| 人工核对 | 可编辑原文与「我／对方」前缀，确认后才调分析模型；保留错字、截断与说话人不确定性 |
| 策略判断 | Jev 七策略 或 DeepSeek 备选；输出主策略、理由、代价、停止条件 |
| 候选回复 | 1–3 条口语短句、排序、「更像我一点」口吻改写、详细分析页 |
| 关系背景 | 联系人档案、关系阶段 / 目标、常驻笔记、按需注入的聊天历史 |
| 回看走势 | 导入聊天 CSV 生成 K 线，或体验五组示例；曲线反映消息方向变化，不是「爱意分数」 |
| 知识库 | 20 份关系知识 + 23 份实战指南（上游完整包），Mac `full` 模式 / Android 按需加载 |
| 悬浮助手 | 悬浮球、长按菜单（截屏识别一次 / 存为联系人 / K 线 / 打开设置）、拖动记忆位置、透明度 |
| 隐私 | 本地 OCR 不上云；云端识图上传截图；分析上传对话文字；密钥存本机 |

## 4. 安卓：从零跑通一轮（本分支重点）

### 4.1 安装 APK

- 要求 **Android 11+、arm64-v8a**，允许「安装未知来源应用」。
- ⚠️ **每次 CI 构建都在全新 runner 上生成新的 debug keystore，签名两两不同**。换版本**必须先卸载旧版**，直接覆盖会提示「应用未安装 / 签名冲突」。卸载会清空本地数据（API Key、笔记、联系人档案），**先抄下配置**。
- 如果还没装过任何版本，直接装最新版即可，中间版本可以跳过。

### 4.2 开三项权限

1. 系统设置 → 无障碍 → 开启「狗头军师 Jev Chat」（描述：读取当前聊天窗口文字，用于生成回复建议，不会自动发送消息）。
2. 悬浮窗权限（允许显示在其他应用上层）。
3. 打开 App 首页，确认「助手已开启」，并填好密钥使 readiness 三项全绿。

**保活（一加 / OPPO 尤其要做）**：允许后台运行、电池优化设为不优化、允许自启动与关联启动、多任务卡片下拉加锁、**不要禁用通知**（前台服务「狗头军师运行中」靠它维持进程优先级）。服务被冻会导致悬浮球消失。

### 4.3 配置模型（三处，滑到底「保存全部设置」）

| 位置 | 推荐值 |
| --- | --- |
| 策略判断 | Jev（TypeSafe，需 Jev Key）**或** DeepSeek 官方 |
| 回复接口 | Base URL `https://api.deepseek.com/v1`，模型 `deepseek-flash`，填 DeepSeek Key |
| 视觉接口 | Base URL `https://api.deepseek.com/v1`，模型 `deepseek-flash`；或干脆不用 |
| 截图识图方式 | **ML Kit 本地**（离线、不耗额度、中文识别稳）／视觉模型（会上传截图） |

- 模型名会**原样**作为 `model` 发给接口。填错（例如 `deepseek-flashsk`）只会显示「请检查模型、密钥和网络」这类统一错误，不会提示拼写问题。正确值是 `deepseek-flash`。
- 选视觉模型前，确认那个模型**真的支持图片输入**；否则只会拿到一段凭空猜的文字。
- 设置页有「测试策略判断」按钮，配完先测一次再保存。
- 视觉 Key 留空时，仅在同 origin 才会复用回复 Key（`RouteKeys` 的隔离规则），避免把密钥发到别的服务。

### 4.4 悬浮球与常驻

- 长按悬浮球 → 菜单：「截屏识别一次」「把当前会话存为联系人」「关系走势 K 线」「打开设置」「隐藏助手（本次）」。
- **常驻开关**：设置 → 外观 →「悬浮球常驻（任何界面都不自动隐藏）」→ 保存。默认关闭时，桌面、系统 UI、本 App 设置页、微信界面会主动收球；打开后这些地方都保留球。
- 首页「助手已开启」是最高优先级总开关，关掉它球一定会消失（即使开了常驻）。
- 悬浮球位置会被记忆，超界坐标会回落到默认位置，避免画到屏幕外。

### 4.5 完整一轮

1. 打开目标聊天窗口（QQ 单聊最稳；群聊识别失败率更高）。
2. 长按悬浮球 →「截屏识别一次」。
3. **核对本轮对话**：文本框可编辑，逐行确认文字与前缀。把你发的行改成 `我：` 开头，其余保持 `对方：`（半角冒号也认）。
4. 点「确认原文并分析」——这一步之后才会调分析模型。
5. 看策略结果、详细分析、候选回复；可点「更像我一点」改写口吻。
6. **复制或填入**草稿，核对收件人和内容，**自己手动发送**。

### 4.6 说话人判错怎么办（必读）

默认本地 ML Kit 整屏 OCR 拿到的是「文字行 + 坐标」，**没有气泡边框**。本分支已加 `ocrLineIsMine()` 按左右留白保守分边，但**长气泡横跨大半屏时仍会归「对方」**——这是刻意的：把对方的话错算成自己说的会让分析完全反向，比漏判严重。

所以**核对页这一步永远不要跳过**。说话人会影响 `latest_from`、自动分析触发、候选回复的口吻样本。

### 4.7 悬浮球没出现？

首页三项全绿但没球，说明权限没问题、是事件层没触发。按 [悬浮窗排障-图文卡.html](./悬浮窗排障-图文卡.html) 的 30 秒自测：切到浏览器看有没有球 → 有球说明是 QQ 控件树识别失效（新包已兜底），没球说明服务被冻，走「关无障碍 → 强停 App → 重开」重绑。

### 4.8 微信截图（实验性，默认关）

上游把微信整条路径关掉了：窗口事件层 drop、手动截屏 toast、`WeChatAdapter` 未注册等 4 处拦截，起因是模拟器上无障碍截图返回全黑。本分支保留**默认关**，但把路径放开；只支持**用户主动发起的整屏截图**，不做后台自动读屏。

1. 设置 → 分析 → 打开「允许微信截图（实验性）」→ 保存全部设置。
2. 同一页把识图方式选 **ML Kit 本地**（别把微信聊天截图发给云端视觉模型）。
3. 进微信聊天页，长按悬浮球 →「截屏识别一次」。微信固定走**系统截屏**：会弹一次 Android 授权，点「立即开始」后**立刻返回刚才那个聊天**，不要切换对象或滚动。
4. 拿到画面 → 本地 OCR → **核对页逐行改 `我：` / `对方：`** → 确认原文并分析。

限制与坑：

- 微信 8.0.52+ 会隐藏无障碍节点文字，所以**不注册自动读控件树**，长按一次截一次。
- 支付、收款码、红包等 FLAG_SECURE 页面会返回全黑，程序会明确提示，不会静默出结果。
- Android 14+ 每次系统截屏都要重新授权；授权期间保留原聊天内容。
- OCR 左右分边阈值按通用气泡布局写就，微信气泡位置需真机验证，**核对页永远不要跳过**。
- 开关关闭时微信界面不显示悬浮球（除非开了「悬浮球常驻」）；此时长按也只会提示去哪开。

## 5. 完整狗头军师 Skill 怎么用

### 5.1 为什么要「独立完整包」

上游 `SKILL.md` 明确写了「不写用户工作区 / 数据不外发 / 不发起网络请求 / 不读取 skill 目录外文件」。桌面与安卓 App 会读屏、读 SharedPreferences、调用云端模型，直接覆盖内置版会自相矛盾。所以本分支：

- 新增 `skills/goutoujunshi/`：原版完整包（MIT LICENSE、121 行 `SKILL.md`、20 份 knowledge、23 份 practical、脚本与 agent 配置），**不覆盖**根目录的桌面定制版（106 行，裁剪了隔离声明、加了桌面 OCR 规则）。
- 切到「完整」时追加 `DESKTOP_RUNTIME_NOTE` / `MOBILE_NOTE`：说明上游声明描述的是 Skill 自身，不是外层 App；桌面/手机 JSON 输出契约优先。

### 5.2 Mac

```bash
cd integrations/jev_mac
./start.command                              # 默认 builtin：根目录桌面定制版
GOUTOU_SKILL_MODE=full ./start.command      # full：三层统一改用完整上游 Skill
```

`core.py` 的 `skill_root()` / `load_bundle()` 统一给 `core.py`、`jev.py`、`deepseek_strategy.py` 三层读取；`scripts/package_mac.py` 已把 `skills/` 打进发布 ZIP。离线验证见 [Mac README](../../integrations/jev_mac/README.md)。

### 5.3 Android

设置 → 分析 →「使用完整狗头军师 Skill」→ 保存。开启后从 `assets/goutou_skill/` 读取：

- `SKILL.md` 核心章节（核心原则 / 输入证据边界 / 每次分析 / 安全边界）
- 按联系人 `goal` 选 2–3 份场景指南（自然接话 / 主动邀约 / 澄清关系 / 修复冲突 / 减少投入 / 结束联系）
- 每轮最多 6000 字，按整行截断

包内 51 个资源：`SKILL.md` + 20 个 `kNN.md` + 23 个 `pNN.md` + 5 个语义别名 + `guide_ocr.md` + `index.json`。`JevQuestions` 刻意不动——英文判断题面经过校准，不能塞长中文规则。

生成器与离线测试：

```bash
python -B scripts/sync_android_skill.py
python -B -m unittest tests.test_android_skill_assets -v
```

### 5.4 不编译也能用（路线 A）

官方现成 APK 没有这个开关，但可以用「知识库 → 新建笔记 → 勾选**常驻（每次分析都带上）**」把 [狗头军师-手机常驻笔记.txt](./狗头军师-手机常驻笔记.txt) 的内容粘进去。常驻笔记不套 1500 字裁剪，每轮都会注入。注意**不要用「从文本导入」**：导入会按空行拆分且默认非常驻。

## 6. 从源码构建 / 出包

本机不需要 Android SDK。push 到 GitHub 后，`.github/workflows/platform-build.yml` 的 `android` job 在 `ubuntu-latest` 上：

```
setup-java 17 → setup-android → sdkmanager "platforms;android-35" "build-tools;35.0.0"
bash gradlew :app:testDebugUnitTest :app:assembleDebug --no-daemon
upload-artifact: goutoujunshi-jev-chat-android-debug
```

> `bash gradlew` 不能写成 `./gradlew`：Windows 初始化的仓库可能把 `gradlew` 记成 `100644`，Linux runner 会报 `Permission denied` / exit 126。

触发路径包含 `integrations/jev_android/**`、`skills/**`、`scripts/sync_android_skill.py` 等。详细出包记录见 [路线B-推送与出包操作卡.txt](./路线B-推送与出包操作卡.txt) 与 [路线B-图文教程.html](./路线B-图文教程.html)。

离线检查（仓库根目录）：

```bash
python3 -B scripts/validate_skill.py
python3 -B -m unittest discover -s tests -q       # 181 tests
```

## 7. 隐私与数据边界

- 本地 OCR（ML Kit）文字识别在设备上完成，不上传。
- 选云端识图会把**截图**发给你配置的视觉服务；发起分析会把**对话文字与必要背景**发给所选模型服务，可能产生费用。
- 密钥存本机（Mac 钥匙串 / Android SharedPreferences），按 origin 隔离，不会发给别的服务。
- 聊天历史默认可关闭；详见 [PRIVACY.md](../../PRIVACY.md)。
- 本分支完整 Skill 包内的上游「本地隔离声明」描述的是 Skill 自身，外层 App 的读屏与模型调用由 App 完成，两者不冲突（运行时适配说明已注入）。

## 8. 常见问题速查

| 现象 | 原因 / 处理 |
| --- | --- |
| 策略判断测试失败，提示检查模型密钥网络 | 多半是模型名拼写错（`deepseek-flashsk` → `deepseek-flash`）；客户端原样发送 `model` |
| 首页三项全绿但没悬浮球 | 权限没问题，是已适配应用控件树读不出来；本分支已兜底补球。再不行按排障卡重绑无障碍服务 |
| 换 APK 提示「应用未安装」 | debug 签名每次都变，先卸载旧版（会清数据） |
| 识别把我的话全算成对方 | 核对页把自己的行改成 `我：`；长气泡会保守归对方 |
| QQ 群识别不稳 | 群聊控件 ID 与单聊不同，优先用单聊 + 截屏识别 |
| 微信没球 / 截取黑屏 | 这一版 Android 明确不支持微信聊天画面 |
| 锁屏回来球没了 | 没给后台/电池/自启动权限，前台服务被冻 |
| 完整 Skill 开着但感觉没变化 | 默认关闭；Android 需保存设置；Mac 需设 `GOUTOU_SKILL_MODE=full` |
| `./gradlew: Permission denied` | 用 `bash gradlew`，并把 `gradlew` 的 git mode 补成 `100755` |
